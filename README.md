# Hi, I'm Tom 

**AI-native software architect.** Programmer. Tinkerer. Coffee-drinker.

I've spent 14+ years building web applications, most of them in learning technology. I rearchitected and lead the **Adapt Authoring Tool**, a Node.js/React course authoring platform. It started as part of the open-source [Adapt](https://www.adaptlearning.org) project and is now used by teams and clients worldwide.

These days I work AI-first: agents build from standards I've documented, automated tests and visual checks verify every change, and I set the direction and review everything that ships. In 2026 that meant a complete product UI with no hand-written code, and 6,000+ tests where there were none.
